# Nuz Zealous - A Portfolio

Welcome to my portfolio site, built as a single-page React app with TypeScript and Tailwind CSS!

<img width="1280" height="720" alt="Image" src="https://github.com/user-attachments/assets/778cb97c-8722-4cf9-bc0d-ac849a5364a9" />

## Getting started

```bash
npm install
npm run dev
```

## Building

```bash
npm run build
```

The typed source lives in `src/`, with components in `src/components`, hooks in `src/hooks`, and project data in `src/data`.

## Notes

Favicon and profile/logo image are expected at `public/`.
